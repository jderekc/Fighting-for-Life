# Fighting for Life

A blocky 3D arena brawler for one young player. Milestone 1: one level, one weapon (sword), enemies, health, apples.

## Play it

```
npm install
npm run build
```

Then double-click `dist/fighting-for-life.html`. It is a single file; no server needed.

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / arrow keys | left stick or D-pad |
| Attack (hold to repeat) | Space, J, K or F | A, X, bumpers or triggers |
| Start / play again | Enter or Space | A or Start |

## Develop

```
npm test        # unit + headless simulation tests
npm run dev     # rebuild on change
```

See `CLAUDE.md` for the architecture, conventions, design decisions and the milestone plan.
